05把图谱转成教学路径

以下是对当前材料的备课建议。三档有大量能力交叉，不宜把某项能力固定等同于某个档位。

反向题：圈出 NOT / FALSE / EXCEPT / all but，逐项标注“支持、矛盾、未交代”，再按题目要求选择。

组合题：对 i–v 每一条独立判断，最后匹配选项；比较两篇文本时要同时验证两边。

证据配对：先有暂定结论，再找最直接证据；若证据对不上，回头重检前一题。

训练节奏：明确问什么 → 回原文定位 → 解释依据 → 比较干扰项 → 用一句话说明答案为什么成立。
